# Audit scope: docs vs code consistency

Audit date: 2026-11-01. Scope: root docs (README.md, ARCHITECTURE.md, DEVELOPMENT_LOG.md, P6_STATUS.md, CHANGELOG.md), docs/adr/*.md, and priority docs/reports/* (rev6-final-integration.md, rev6-hardening-integration.md, p2-p6-final-verification.md, p62-release-closure.md, final-attestation.json, rev6-real-benefit-result.md, pr4a-five-arm-eval-report.md, p6-fair-eval.md, p5-eval-report.md, plus rev5-final-integration.md and docs/P62_STATUS.md as referenced). Method: static cross-check only (no repo commands executed) — file reads, git object-database reads, grep, and independent recomputation of documented digests via `git cat-file | sha256sum`.

## Verified facts summary

No P0 (fabricated evidence) was found: every evidence artifact whose digest this audit recomputed — the commit attestation (composite + binding over 257 git blobs), three bound report hashes, and the eval-lib digest — matches byte-for-byte. The development-log timeline is consistent with git history (28 commits, 2026-10-21..10-31, remote = tang19-chao/dsh-plugin-evo-harness as claimed). The reports are unusually honest about limits: real-model benefit, four-arm ablation, real memory writes, guarded-active, publish, and remote-CI results are all explicitly marked not-run/not-evaluable rather than claimed. The real defects found are one front-page factual contradiction (runtime dependencies) and stale "open item" ledger entries that the code has already fixed.

## Findings

### [DOCS-1] README Requirements table claims "Runtime dependencies: none" while the package declares and imports a runtime dependency (P1)
- File: README.md:38 + contradicting code package.json:62-63, src/index.ts:20
- Claim: `| Runtime dependencies | none | the package declares no `dependencies`; only `devDependencies` (TypeScript, Vitest, `@types/node`) |`
- Reality: package.json:62-63 declares `"dependencies": { "@deepseek-ai/schemastery": "3.18.4" }`, and the plugin entrypoint statically imports it (src/index.ts:20 `import z from '@deepseek-ai/schemastery'`; also used by src/dsh-bridge/model-config.ts, which documents the dependency at its lines 24-45). The dependency was added in commit 7e73b3f (2026-10-21, "feat(dsh): add DSH host bridge, real event triggers, and volatile model config") and the README was edited as recently as 2026-10-31 (rev6-hardening count sync) without fixing this row. The same row's parenthetical is also incomplete: devDependencies additionally include `esbuild` (required by `pnpm run build` via scripts/build.mjs and by `check:docs`' config-leaf bundler).
- Fix: Correct the row, e.g. "Runtime dependencies: `@deepseek-ai/schemastery` (config/settings-page schema); devDependencies: TypeScript, Vitest, `@types/node`, esbuild" — and re-run `pnpm run check:docs` is not needed (the row is outside the gated leaves), but CI docs hygiene should ideally extend to this table.
